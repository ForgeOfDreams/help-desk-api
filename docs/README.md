# Индекс инженерной документации

- `architecture.md` — структура приложения и ответственность слоёв.
- `domain-model.md` — сущности, enum, правила предметной области и инварианты.
- `api-contract.md` — маршруты, доступ и форматы операций.
- `security.md` — JWT, роли, токены действий, rate limiting и секреты.
- `database.md` — MySQL, Doctrine, миграции и изоляция тестовой базы.
- `configuration.md` — Compose-файлы и переменные окружения.
- `development.md` — локальная разработка, запуск и команды проверки.
- `ci-cd.md` — проверки GitHub Actions и публикация релизных образов.
- `code-quality.md` — форматирование, Composer и repository lint.
- `operations.md` — эксплуатационные проверки, логи и production-ограничения.
- `implementation-status.md` — функциональные возможности и то, что требует отдельной
  реализации/подтверждения.
- `decisions.md` — основные инженерные решения и последствия.
- `troubleshooting.md` — типовые ошибки конфигурации и CI.

Документы написаны как инженерное описание, без диаграмм и графиков. Фактическую реализацию следует
подтверждать исходным кодом, конфигурацией, миграциями, тестами и OpenAPI-контрактом.
